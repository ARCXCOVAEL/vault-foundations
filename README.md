## What it does

- Filters excluded files early and supplies bounded performance controls, status and recovery.
- Maintains folder-index, root and optional Home navigation that links to original documents.
- Preserves ordinary creation, editing, moves, renames, note contents and links.
- Keeps necessary licensing and purchases separate from local vault processing.

If full navigation access expires, new paid automation pauses while notes,

## Getting started after release

These steps describe an authorized package after release; downloads and enrollment remain closed.

For an authorized package: save your work, keep an ordinary vault backup and close the application normally. Put the package's `vault-foundations` folder in your vault's `.obsidian/plugins/` folder, reopen and enable **Vault Foundations** in Community Plugins. Open its settings, choose exclusions deliberately and preview folder notes before enabling their upkeep. Generic defaults do not assume a Knowledge folder or any particular drive.
