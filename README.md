# Vault Foundations

[Product website](https://vault-foundations.arcxcovael.com/) · [Download the Free installer](https://license.arcxcovael.com/downloads) · [Vault Foundations Guide](https://vault-foundations.arcxcovael.com/guide/)

Early file filtering, responsive background work and optional folder-note navigation for your existing vault and native graph.

Version 1.1.0. Published and maintained by ARCXCOVAEL LLC.

Vault Foundations gives folders a place in your graph through small Markdown index notes that link to original documents. Create, edit, move and rename your documents normally. One local background worker keeps configured folder links current; it does not copy your original documents or replace the native graph.

## For developers and AI workspaces

Use Obsidian to keep project overviews, architecture, decisions, tasks and runbooks connected to your development work. Vault Foundations helps filter unwanted repository noise and, with Full access, maintain configured folder-note navigation. Optional Graph Views adds Overview, Focused Writing and Structure views of those real links.

### Watch your repository grow while agents work

Use Obsidian as a live window into the documentation in your repository. Keep a contents note and the native graph open while you or your agents add notes, create folders, move documents and update links, so you can see the project take shape.

Obsidian displays changes to included vault files. With **Vault Foundations Full navigation enabled**, configured folder tables of contents, the root index and optional Home navigation refresh automatically as eligible files are added, moved or removed. Their real Markdown links let the native graph and optional Graph Views Structure view grow with your project. You do not need to reopen the vault for each update.

Updates are batched rather than guaranteed to appear instantly. Native file detection and indexing affect visibility; a 60-second catch-up pass covers missed events while Obsidian is open, and reopening catches up later. Only included, eligible content participates: the graph follows notes and links and does not automatically turn every code file or filesystem folder into a node. Free keeps native note viewing and existing generated links available; automatic navigation upkeep requires active Full access.

Your preferred AI can assist with notes, repositories and plugin setup through the file or app tools you choose to provide. For bulky repositories or duplicate-looking nodes, investigate full paths first; use targeted exclusions and focused views before approved, backed-up cleanup. Different notes, legitimate clones and worktrees must not be merged just because their labels match.

The included **GUIDE.md → For developers and AI workspaces** provides a reusable setup prompt, a small-project starting workflow and safe decluttering practices. Check current compatibility and your assistant’s actual permissions; no AI control bridge is bundled with either plugin.

## Recommended companion: Graph Views

For a richer experience, we recommend using **Vault Foundations with [Graph Views](https://community.obsidian.md/plugins/graph-views)**, also created and maintained by ARCXCOVAEL LLC. Vault Foundations keeps configured folder and document links current; Graph Views helps you explore and shape the presentation of those same connections on the native graph.

Use **Overview** for the wider admitted vault, **Focused Writing** around the notes you are working on, and **Structure** to follow the real links in your chosen contents or index note. Shared branches, cross-links and backlinks remain part of your vault. You can choose your own writing outline as the root rather than use the directory index.

Graph Views is a separate, optional, free public beta under MPL-2.0. Install and enable it separately; it is not bundled or required, and neither product changes the other's license or access. Both work with the native graph. Large graphs can still be expensive; this recommendation is about navigation and presentation, not a guaranteed speed increase. See the guide for the paired setup and exact compatibility.

## Installation and first use

Use the official authorized release assets. A Community listing is not required for manual installation; this guide does not claim directory acceptance.

For an authorized package: save your work, keep an ordinary vault backup and close the application normally. Put the package's `vault-foundations` folder in your vault's `.obsidian/plugins/` folder, reopen and enable **Vault Foundations** in Community Plugins. After first enabling it, save your work and restart Obsidian once before checking early filtering. Open its settings, choose exclusions deliberately and preview folder notes before enabling their upkeep. Generic defaults do not assume a Knowledge folder or any particular drive.

Only Windows desktop versions 1.14.4 and 1.14.5 are currently verified. Unknown hosts deliberately refuse early unfiltered traversal until compatibility is checked. Android, macOS and Linux are not advertised as supported by version 1.1.0.
